# Obsidian Detailing

Учебный проект по курсу Web Technologies 1 (Front End): Midterm и Endterm.
Сайт детейлинг-студии премиум-класса в Астане.

- Репозиторий: https://github.com/tyn-aisha/web_endterm
- Сайт: https://tyn-aisha.github.io/web_endterm/

## Страницы и ответственные

| Страница | Что внутри | Автор |
|---|---|---|
| index.html | Hero, счётчики, преимущества, шаги, отзывы с фильтром, поиском и сортировкой | Imanalyuly Dinmukhammet |
| contacts.html | Контакты, график с «открыто сейчас», карта, быстрые ответы, форма | Imanalyuly Dinmukhammet |
| services.html | Пакеты, прайс с поиском/фильтром/сортировкой и расчётом, подбор пакета, FAQ | Seitzhan Yeraly |
| works.html | Слайдер до/после, галерея с фильтром и лайтбоксом | Seitzhan Yeraly |
| booking.html | Форма записи, расчёт цены, промокод, свободные слоты | Bertan Maidabek |
| account.html | Личный кабинет: регистрация, вход, профиль, цены для класса авто, редактирование и удаление аккаунта (localStorage) | Tynyshtykbay Aisha |

## Структура

```
css/   style.css (общие стили), forms.css, tools.css и по одному файлу на страницу
js/    common.js (jQuery-эффекты), validate.js (валидация форм), data.js (общие данные) и по одному файлу на страницу
img/   иллюстрации (SVG)
```

## Технологии

HTML5, CSS (Flexbox, Grid, переменные, media queries), Bootstrap 5.3, JavaScript, jQuery 3.7.

## Источники

- Иллюстрации: созданы с помощью AI (Claude, Anthropic) и доработаны командой
- Шрифты: Google Fonts (Oswald, Inter)
- Карта: OpenStreetMap
